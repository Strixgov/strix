## Known hard cases

The recall experiment's adversarial corpora (`experiments/jev-recall`) target the gaps the detector documents and does not claim to cover: lone surnames, unlisted names, non-Latin names, unlabelled account numbers, names deep in long records. These numbers are expected to be poor; they are the case for the local detection signal (see `docs/architecture/governed-egress-local-signal-design-review-v1.md`), which is not enabled. Since detector 0.8.0 a doctor's name is kept by default (a provider, not the patient; operator decision Q1, 2026-10-06), so four labelled names in these corpora (Dr. Varga, Dr. Lincoln, Dr. Mayo, Dr. Ambrose) now count as survived by design, and two clinic names they used to drag along are no longer flagged.
